# Smart School Management System

A complete, modern, professional and fully responsive School Management System website.

## Features

- **Role-based Login**: Administrator, Teacher, Student, Parent, Accountant
- **Admin Dashboard** with statistics cards and Chart.js charts
- **Student Management**: Full CRUD, search, filter, view profile
- **Teacher Management**: Full CRUD
- **Parent Management**
- **Classes & Sections**
- **Attendance Management**: Mark present/absent/leave/late
- **Fee Management**: Structure, collect fees, print receipts
- **Examination & Results**: Result cards with print
- **Timetable**, **Homework**, **Notice Board**
- **Staff**, **Payroll**, **Library**, **Transport**
- **Reports**, **Communication**, **Settings**
- **Global Search**
- **Responsive** design (mobile, tablet, desktop)
- **localStorage** persistence with realistic demo data

## How to Run

1. Open `index.html` in a modern browser (Chrome, Firefox, Edge).
2. Login with any demo credentials above.
3. Explore the sidebar modules according to your role.

No server required — pure HTML/CSS/JavaScript with Bootstrap 5, Chart.js and Font Awesome.

## Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- Bootstrap 5.3
- Chart.js 4
- Font Awesome 6
- localStorage for data persistence
